# Private Line VPN для Chrome

Это **расширение Chrome + локальный Xray**, а не независимый от компьютера Web-VPN. Для VLESS Reality нужен локальный компонент: обычное расширение Chrome не умеет самостоятельно выполнять протокол VLESS. Комплект не включает ключи подписчиков: свой VLESS-ключ пользователь получает в Telegram-боте.

## Установка на Windows

1. Скачайте ZIP из Telegram-бота командой `/chrome` либо в админке Private Line (раздел VPN-серверов).
2. Распакуйте ZIP в постоянную папку. Откройте `chrome://extensions`, включите **Режим разработчика**, нажмите **Загрузить распакованное расширение** и выберите папку `extension`.
3. Скопируйте **ID расширения** со страницы `chrome://extensions` (32 латинские буквы).
4. Установите Python 3 с https://www.python.org/downloads/windows/ (если нет).
5. Дважды нажмите **SETUP-WINDOWS.cmd** в распакованной папке, вставьте ID расширения. Если требуется ручная установка, в PowerShell из каталога ZIP:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\\native\\install_windows.ps1 -ExtensionId ВАШ_ID_РАСШИРЕНИЯ
   ```
   Установщик скачает Xray 26.6.27 из официального GitHub XTLS. Можно использовать ранее скачанный бинарник через `-XrayPath "C:\\path\\xray.exe"`.
6. Перезапустите Chrome, откройте расширение Private Line, вставьте ссылку `vless://...` из Telegram-бота и нажмите **Подключить VPN**.
7. Расширение включит прокси браузера **только после успешного HTTPS-запроса через VLESS Reality** и покажет проверенный внешний IP. Для отключения нажмите **Отключить**.

**Важно.** Chrome использует локальный SOCKS5 `127.0.0.1:19590`, Xray подключается к вашей VPN-ноде. Из браузера проксируются HTTP/HTTPS и TCP. Это **не системный VPN** и не защищает другие приложения. Расширение старается отключать непроксируемый WebRTC/UDP, но корпоративные политики Chrome могут блокировать эту настройку. Для системного VPN используйте полноценное VPN-приложение.

## Linux / macOS

Понадобятся Python3 и Xray 26.6.27. После установки распакованного расширения:
```bash
bash native/install_unix.sh ВАШ_ID_РАСШИРЕНИЯ /полный/путь/к/xray
```
Перезапустите Chrome.

## Диагностика

- «Локальный клиент не установлен» — проверьте установку native host и совпадение ID, закройте Chrome полностью и откройте заново.
- «Порт занят» — закройте другую программу, использующую 19590.
- «Не удалось пройти реальную HTTPS-проверку» — клиент не может установить VLESS Reality туннель с **этого компьютера/провайдера**. Успех сервера в дата-центре сам по себе не доказывает доступности VPN из вашего региона.
- VPN на сервере и на локальном клиенте использует Xray 26.6.27. Неправильные UUID, serverName, publicKey или shortId приводят к ошибке до включения прокси.

Безопасность: сохранённая копия ключа находится в файле профиля локального Xray (`%LOCALAPPDATA%\PrivateLineChrome\client.json` на Windows); расширение не сохраняет его в Chrome storage. Пользователь должен защищать учётную запись Windows. Секрет **не включён в скачиваемый ZIP**. Никому не отправляйте свои VLESS-ссылки или содержимое `client.json`.

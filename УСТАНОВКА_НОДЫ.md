# Установка VPN-ноды: пошаговая инструкция

> Инструкция написана для людей без опыта программирования.
> Вся установка занимает **10–20 минут**.

---

## Что такое нода?

Нода — это отдельный сервер (VPS), который будет пропускать через себя VPN-трафик ваших пользователей.
Чем больше нод — тем больше стран и тем устойчивее сервис.

---

## Шаг 1. Арендуйте VPS-сервер

Подойдёт любой хостинг: **Hetzner, DigitalOcean, Vultr, Timeweb, Aeza** и другие.

**Минимальные требования:**
- ОС: **Ubuntu 22.04** или Ubuntu 20.04
- RAM: 512 МБ (рекомендуется 1 ГБ)
- CPU: 1 ядро
- Диск: 10 ГБ
- Сеть: без ограничений по трафику (или от 1 ТБ/мес)

После аренды вы получите:
- **IP-адрес сервера** (например: `185.100.200.50`)
- **Логин:** обычно `root`
- **Пароль** (или SSH-ключ)

---

## Шаг 2. Получите токен регистрации

Токен — это секретный код, который позволяет скрипту автоматически добавить ноду в вашу систему.

**Как получить токен:**

1. Войдите на **основной сервер** (где работает бот) по SSH:
   ```
   ssh root@<IP вашего основного сервера>
   ```

2. Если токен ещё не задан — сгенерируйте его одной командой:
   ```bash
   python3 -c "import secrets; print(secrets.token_urlsafe(32))"
   ```
   Скопируйте результат, например: `mK7xP2qR9vLw4nT8eY1cZ6aB3jF5iD0h`

3. Добавьте токен в файл `.env`:
   ```bash
   cd /opt/private-line
   echo "NODE_REGISTER_TOKEN=mK7xP2qR9vLw4nT8eY1cZ6aB3jF5iD0h" >> .env
   docker compose restart admin
   ```
   *(замените `mK7xP2qR9vLw4nT8eY1cZ6aB3jF5iD0h` на ваш сгенерированный токен)*

4. Теперь токен также виден в Admin Panel → **Серверы** → раздел «Автоматическая регистрация нод».

---

## Шаг 3. Подключитесь к новому VPS по SSH

**На Windows:** используйте программу [PuTTY](https://putty.org) или встроенный терминал (Win+R → `cmd`).

**На Mac/Linux:** откройте Терминал.

Введите команду:
```bash
ssh root@185.100.200.50
```
*(замените IP на ваш)*

Если спросит пароль — введите пароль от VPS.

---

## Шаг 4. Запустите установщик

Выполните одну команду в терминале (на ноде-сервере):

**Способ 1 — скопировать с основного сервера** (работает всегда, репозиторий может быть приватным):
```bash
scp root@<IP_ОСНОВНОГО_СЕРВЕРА>:/opt/private-line/install_node.sh ~/install_node.sh
chmod +x ~/install_node.sh
bash ~/install_node.sh
```
Замените `<IP_ОСНОВНОГО_СЕРВЕРА>` на IP сервера, где работает бот.

**Способ 2 — скачать с GitHub** (только если репозиторий публичный):
```bash
curl -fsSL "https://raw.githubusercontent.com/venomimonstro/private-line-tg-claude/claude/private-line-mvp-cmx4Z/install_node.sh" | bash
```

---

## Шаг 5. Следуйте подсказкам установщика

Установщик задаст несколько вопросов. Просто отвечайте на них:

| Вопрос | Что вводить | Пример |
|--------|------------|--------|
| Название сервера | Любое понятное название | `Germany-1` |
| Страна (на английском) | Страна, где стоит VPS | `Germany` |
| Город | Город VPS | `Frankfurt` |
| Код страны ISO | Двухбуквенный код | `de` |
| URL вашего сервера | Адрес основного сервера с портом | `http://185.200.100.50` |
| Токен регистрации | Токен из Шага 2 | `mK7xP2qR9vLw4nT8eY1cZ6aB3jF5iD0h` |

После этого установщик:
1. Установит Docker и зависимости (~2 минуты)
2. Установит Outline VPN (~3 минуты)
3. Настроит файерволл
4. **Автоматически зарегистрирует ноду в вашей Admin Panel**

---

## Шаг 6. Проверьте результат

1. Откройте **Admin Panel** вашего бота
2. Перейдите в раздел **Серверы**
3. Новая нода должна появиться в списке со статусом `active`
4. Нажмите **«Проверить соединение»** — должна появиться зелёная галочка ✅

Если нода появилась — готово! Пользователи уже могут получать VPN-ключи на этот сервер.

---

## Что делать если что-то пошло не так?

### Нода не появилась в Admin Panel

Скорее всего, установщик не смог подключиться к Admin Panel. Добавьте ноду вручную:

1. Зайдите в Admin Panel → Серверы → Добавить сервер
2. В поле **API URL** введите значение из файла `/root/outline_node_info.txt` на ноде:
   ```bash
   cat /root/outline_node_info.txt
   ```
3. Нажмите «Добавить»

### Статус «Недоступен» при проверке соединения

Убедитесь, что порты открыты на ноде:
```bash
ufw status
```
Должны быть открыты порты SSH (22) и порт управления Outline (виден в выводе `docker ps`).

### Outline не установился

Проверьте, что Docker работает:
```bash
docker ps
```
Если не работает — перезапустите установщик.

## Полезные команды на ноде

```bash
# Посмотреть статус Outline
docker ps --filter "name=shadowbox"

# Посмотреть сохранённую конфигурацию
cat /root/outline_node_info.txt

# Перезапустить Outline
docker restart shadowbox
```

После выполнения инструкции у вас будет:
- ✅ Работающая VPN-нода на отдельном сервере
- ✅ Нода автоматически добавлена в Admin Panel

Для добавления следующей ноды — просто арендуйте ещё один VPS и повторите с Шага 3.

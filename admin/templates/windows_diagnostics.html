Windows-клиент и отчёты

Отправка только после нажатия пользователем «Отправить диагностику». Не принимаем VLESS-ссылки, UUID, пароли, сырые логи или IP.

Персональная автоматическая установка: выберите пользователя с активной подпиской. IP, VLESS-ключ и диагностический токен в программе вводить не нужно.

Либо клиент получает свой комплект через команду /windows в Telegram. Одноразовый код действует 24 часа. Не пересылайте персональный ZIP.

Общий архив (без привязки, только для диагностики файлов)

Скачивание не означает установку. После загрузки выберите «Извлечь все» и откройте распакованную папку.

1. Запустите INSTALL-WINDOWS.cmd и дождитесь сообщения PRIVATE LINE IS INSTALLED AND LAUNCHED.
2. Запустите CHECK-INSTALL.cmd, чтобы увидеть статус «УСТАНОВЛЕНО» или конкретную ошибку.
3. Откройте ярлык Private Line на рабочем столе, вставьте ключ и нажмите «Подключить».

Отчёты будут приходить автоматически из авторизованного Windows-клиента, если пользователь разрешил диагностику.

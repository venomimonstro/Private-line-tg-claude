Проверка с вашего Windows-компьютера

Скачайте один диагностический файл для Windows, запустите его без VPN двойным щелчком и вставьте ключ из Telegram в скрытый запрос. Скрипт проверит прямой интернет, доступность ноды, вход VLESS/REALITY, сайт через VPN и DNS на порту 853.

Откройте скачанный Probe-PrivateLine.cmd двойным щелчком. Файл не устанавливает клиент и не меняет сетевые настройки. Xray загружается во временную папку с проверкой SHA-256. Ключ не передаётся на основной сервер; отправляются только коды этапов. Файл содержит одноразовый код отправки, действующий 1 час. Не пересылайте его другим.

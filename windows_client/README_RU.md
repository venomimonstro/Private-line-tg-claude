# Private Line для Windows

Это отдельное Windows-приложение с интерфейсом подключения и диагностикой; установка расширения Google Chrome не требуется.

1. Распакуйте ZIP в любую папку.
2. Запустите **INSTALL-WINDOWS.cmd**. Установщик скачает Xray 26.6.27 из официального релиза XTLS на GitHub, проверит версию, установит приложение только для вашей учётной записи и создаст ярлык **Private Line** на рабочем столе.
3. Вставьте собственный ключ из Telegram-бота (команда `/mykey`), нажмите **Подключить**.
4. Когда HTTPS-проверка пройдёт, Windows/Chrome получат локальный SOCKS5-прокси. Нажмите **Отключить**, чтобы восстановить прежние параметры прокси.
5. Для диагностики откройте в админке **Диагностика Windows**, скопируйте HTTPS-адрес основного сервера и токен, вставьте их в приложение, отметьте согласие и нажмите **Отправить диагностику**.

Сервер получает только коды этапов (бинарник, профиль, TCP, SOCKS, HTTPS, прокси). В диагностике нет UUID, паролей, содержимого ключей и сырых логов; отправка только после нажатия кнопки. В админке появится ID отчёта.

**Техническая граница:** это Windows/Chrome прокси, **не полноценный TUN/WireGuard VPN**. Не все Windows-приложения обязаны использовать системные proxy settings. В частности, UDP-трафик и отдельные игры не будут перенаправляться. Не запускайте одновременно несколько VPN/proxy программ.

**Если всё ещё нет подключения:** диагностика отличит недоступность порта ноды из домашней сети, неправильный профиль, локальную ошибку запуска Xray и отказ HTTPS-туннеля. Не передавайте свои VLESS-ключи или файлы `profile.json` в службу поддержки. Не делитесь токеном диагностики публично.

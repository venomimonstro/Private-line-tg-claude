# Private Line для Windows — установка и проверка

**Скачать файл ≠ установить приложение.** После нажатия кнопки скачивания в админке вы получаете `private-line-windows.zip`, а не установленную программу.

## Установка Windows 10/11 x64

1. Скачайте `private-line-windows.zip` из **Админка → Диагностика Windows** или через Telegram-бота `/windows`.
2. Нажмите правой кнопкой на ZIP → **Извлечь все**. Не запускайте файлы прямо внутри ZIP.
3. В распакованной папке запустите **INSTALL-WINDOWS.cmd**. Откроется окно с этапами 1–5. Может понадобиться разрешить запуск обычного сценария от вашего имени; права администратора не требуются.
4. Дождитесь сообщения **PRIVATE LINE IS INSTALLED AND LAUNCHED** и отдельного окна «Установка завершена». Раньше этого сообщение «успешно установлено» не показывается.
5. Если сомневаетесь — запустите **CHECK-INSTALL.cmd**. Появится отдельное окно с результатами проверки Xray, файлов и ярлыка.
6. Откройте ярлык **Private Line** на рабочем столе, вставьте свой `vless://` ключ из `/mykey` и нажмите **Подключить**. Пока нет сообщения «Подключено» с внешним IP, VPN не считается работающим.

Установщик сохраняет приложение в `%LOCALAPPDATA%\PrivateLineWindows`. При повторном запуске выполняется безопасное восстановление файлов и проверки, без удаления сохранённого VPN-профиля. Если загрузка Xray из GitHub не удалась, устанавливающий сценарий отобразит ошибку; загрузка ZIP не приравнивается к успешной установке.

## Диагностика

В Windows-клиенте есть кнопка **Проверить установку**. Она проверяет наличие Xray и ярлыка. Для диагностики VPN запустите **Подключить**: проверяются профиль, TCP-доступность ноды, локальный SOCKS и настоящий HTTPS-запрос через VPN.

Чтобы передать отчёт: откройте **Админка → Диагностика Windows**, скопируйте HTTPS-адрес и токен, вставьте их в приложение, отметьте согласие и нажмите **Отправить диагностику**. В админке появится ID отчёта. Отправка не автоматическая: только по вашему подтверждению и только коды этапов, без VPN-ключей, UUID, IP-адресов и сырых журналов.

## Ограничения

Это клиент для проксируемого Windows/Chrome TCP-трафика, **не системный TUN/VPN для всех приложений**. Не все Windows-программы используют настройки WinINET, а UDP/игры в этот туннель не направляются. Одновременная работа других VPN-прокси может мешать подключению.

При ошибке установки сообщите её короткий код из окна (например, `XRAY_DOWNLOAD_INCOMPLETE` или `GUI_NOT_CONFIRMED`), **не присылайте VLESS-ключ и содержимое `profile.json`**.
